Vibe VPN — Aurora Ultimate v10
================================

Цель релиза: максимально облегчить вращение глобуса и изменение размера главного окна,
не ломая Aurora UI, темы, локации, страницы, настройки, иконки и запуск EULA.

Что сделано в v10
-----------------
1. При интерактивном изменении размера окна приложение больше не проецирует глобус заново
   на каждое событие Configure. Оно масштабирует последний готовый растр, а после паузы
   выполняет один полный детализированный рендер.
2. Пока пользователь изменяет размер окна, декоративная анимация ставится на паузу.
   После завершения активируется снова.
3. Canvas-level и root-level таймеры объединены; финальный рендер отменяет дублирующий
   canvas settle-job, чтобы не было двух тяжёлых рендеров подряд.
4. Во время вращения глобус рендерится в маленьком framebuffer (~110k пикселей максимум),
   с редкой сеткой и пониженной частотой. После отпускания мыши возвращается детализация.
5. Точки суши группируются по цветам и рисуются пакетно через Pillow ImageDraw.point()
   вместо тысяч отдельных draw.ellipse() вызовов. Часть точек добавляется эллипсами для объёма.
6. Полный растр ограничен по разрешению/пикселям на больших экранах, затем масштабируется
   до размеров Canvas. Это снижает пиковую нагрузку и расход памяти на 4K/высоком DPI.
7. На время resizing скрытые глобусы не перерисовываются; обновляется только глобус активной страницы.
8. Источник последнего растра хранится отдельно для быстрого preview без пересчёта координат.
9. Сохранены страницы, 196 каталоговых локаций, темы, иконки, профиль, тарифы, настройки,
   Vibi, история и диагностика.
10. EULA.exe сохранён побайтно без изменений; лаунчер продолжает запускать EULA при старте.

Сборка одного EXE в Windows
---------------------------
1. Распакуйте архив полностью в отдельную папку.
2. Установите Python для Windows, если его нет.
3. Запустите build_one_exe.bat.
4. Ожидаемый файл: dist\VibeVPN.exe.

Скрипт сборки устанавливает PyInstaller и Pillow. Готовый Windows EXE в этой среде
не собирался, поэтому финальную сборку нужно проверить на целевом компьютере.

Важные ограничения
------------------
Это UI-прототип. Статусы подключения, ping и скорость в интерфейсе демонстрационные.
Реальный VPN-движок, серверная выдача Telegram-ключей, kill switch, DNS-защита и сетевые
фильтры требуют настоящей backend/OS-интеграции. Настройки, помеченные Backend/Windows,
сами по себе не обеспечивают сетевую защиту.
